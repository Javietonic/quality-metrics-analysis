# Quality Metrics Analysis

Personal data analytics project built using a simulated dataset based on 
real metrics tracked in my role as a Quality Representative in a contact 
center. Built to practice the full data workflow: cleaning, visualization, 
and statistical analysis.

## Projects

### 1. Idle Time vs Contact Rate
Tested whether idle time drives contact rate — a common assumption in 
contact center operations. Found almost no relationship (R²=0.025).
🔗 [View on Tableau Public](https://public.tableau.com/views/PRSContactsperHourandIdleteamrelation/Hoja1?:language=es-ES&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

### 2. Performance Dashboard
Built a unified dashboard combining Answer Rate, Quality Scores, Work 
Items per Hour, and Non-productive time across 8 months.
🔗 [View on Tableau Public](https://public.tableau.com/views/PerformancepanelforPRSJan-AugHypothethical/PerfomancePanelforPRSJan-Aug?:language=es-ES&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

### 3. Quality Score Drivers
Ran a correlation analysis across multiple daily metrics (idle time, 
answer rate, on-contact time, non-productive time) to find what best 
predicts scoring quality. No variable showed a strong relationship — 
idle time was closest, explaining only 10% of variation.
🔗 [View on Tableau Public](https://public.tableau.com/views/QualityScoreDriversAcorrelationanalysis/QualityScoreDriversAcorrelationanalysis?:language=es-ES&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)
